🚀 Getting Started

Prerequisites

  • Node.js 14 or higher
  • MongoDB running locally
  • For mobile: Android Studio or Xcode

Quick Start

Run the quick start script:

QUICKSTART.bat (Windows) or QUICKSTART.sh (Mac/Linux)

Manual Setup

1. Start MongoDB:

mongod

2. Start Backend:

cd backend && npm install && npm start

Server runs on http://localhost:5000

3. Start Web App:

cd web && npm install && npm run dev

App runs on http://localhost:5173

4. Start Mobile App:

cd mobile && npm install && npm run android
💡 Tip: Open each command in a separate terminal window so all services run simultaneously.

🔌 API Endpoints

Reminders

Method Endpoint Description
GET /api/reminders Get all reminders
POST /api/reminders Create new reminder
GET /api/reminders/:id Get single reminder
PATCH /api/reminders/:id Update reminder
DELETE /api/reminders/:id Delete reminder

Notifications

Method Endpoint Description
GET /api/notifications Get and clear pending notifications

Health

Method Endpoint Description
GET /api/health Check if server is running

🧪 Testing

Using Postman

  1. Open Postman
  2. Import POSTMAN_COLLECTION.json
  3. Set base_url variable to http://localhost:5000/api
  4. Run requests from the collection

Using curl

# Create a reminder
curl -X POST http://localhost:5000/api/reminders \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Team Meeting",
    "date": "2025-12-11",
    "time": "15:00",
    "repeat": "once"
  }'

# Get all reminders
curl http://localhost:5000/api/reminders

# Check notifications
curl http://localhost:5000/api/notifications

🚨 Troubleshooting

Issue Solution
MongoDB connection error Ensure MongoDB is running: mongod
Port 5000 already in use Change PORT in .env file or kill process using the port
CORS errors Backend already has CORS enabled; check browser console for details
Mobile app can't reach backend Use 10.0.2.2 on Android emulator or machine IP on physical device
Dependencies installation fails Delete node_modules folder and run npm install again
