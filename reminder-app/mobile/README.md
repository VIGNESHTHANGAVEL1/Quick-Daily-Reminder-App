# Reminder App Mobile

React Native app for the Daily Reminder App (Android & iOS).

## Setup

1. Install dependencies:
```bash
npm install
```

2. For Android:
```bash
npm run android
```

For iOS:
```bash
npm run ios
```

## Features

- View all reminders
- Create new reminders
- Edit existing reminders
- Mark reminders as completed
- Delete reminders
- Local push notifications

## Note

For local development, use `10.0.2.2:5000` for Android emulator API calls (instead of `localhost`).
