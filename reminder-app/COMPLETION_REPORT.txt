🚀 QUICK START COMMANDS

Step 1: Prepare MongoDB
  mongod

Step 2: Start Backend (Terminal 1)
  cd backend && npm install && npm start
  Runs on: http://localhost:5000

Step 3: Start Web (Terminal 2)
  cd web && npm install && npm run dev
  Runs on: http://localhost:5173

Step 4: Start Mobile (Terminal 3)
  cd mobile && npm install && npm run android
  OR: npm run ios

📝 API ENDPOINTS REFERENCE

Health Check
  GET /api/health
  → Check if server is running

Reminders CRUD
  GET /api/reminders
    → Get all reminders (sorted by date/time)

  POST /api/reminders
    → Create new reminder
    Required fields: title, date (YYYY-MM-DD), time (HH:MM)
    Optional fields: description, repeat, status

  GET /api/reminders/:id
    → Get single reminder by ID

  PATCH /api/reminders/:id
    → Update reminder (any field)

  DELETE /api/reminders/:id
    → Delete reminder permanently

Notifications
  GET /api/notifications
    → Get and clear pending notifications
    Returns array of triggered reminders
