# Reminder App Web

React-based web frontend for the Daily Reminder App.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:5173`

## Build

```bash
npm run build
```

## Features

- View all reminders
- Create new reminders
- Edit existing reminders
- Mark reminders as completed
- Delete reminders
- Real-time notification polling
- Toast notifications for triggered reminders
